You are a senior full-stack software engineer and system architect.

Your task is to design and generate the architecture and starter implementation for a **full-stack web application called "AmigoSync"**.

AmigoSync is a smart group coordination platform that helps friends stay connected when they split into smaller groups during trips or outings.

---

PROJECT PROBLEM

When a group of friends goes outside together (for example 8 friends going out from a college hostel), they often split into smaller groups to complete different tasks.

Example:

* 2 friends go shopping
* 2 friends go to a restaurant
* 4 friends go to the beach

After finishing their activities, it becomes difficult to:

* know where everyone is
* communicate with specific subgroups
* reconnect easily

Existing messaging apps allow chatting but do not provide tools specifically for **trip coordination and subgroup management**.

AmigoSync solves this problem by providing trip rooms, subgroup communication, live location sharing, and smart proximity alerts.

---

MAIN FEATURES

1. USER AUTHENTICATION

Users must be able to create accounts and log in.

Authentication features:

* Email and password login
* Secure password hashing
* JWT-based authentication
* User profile

User profile fields:

* name
* email
* avatar/profile photo
* phone number

---

2. TRIP ROOM SYSTEM

Users can create a trip room when starting an outing.

Room features:

* create room
* automatically generate unique room code
* friends can join using the room code
* view all members in the room

Example:
Room Name: Beach Trip
Members: 8 friends

---

3. SUBGROUP MANAGEMENT

Inside each room, users should be able to create subgroups.

Examples:

* Shopping Group
* Food Group
* Beach Group

Features:

* create subgroup
* join subgroup
* leave subgroup
* see members of each subgroup

---

4. REAL-TIME CHAT SYSTEM

Users should be able to send messages in real time.

Messaging types:

* message entire room
* message a specific subgroup
* private message to a single user

Messages should appear instantly using WebSockets.

---

5. LIVE LOCATION SHARING

Users can share their real-time location.

Location sharing options:

* share with entire room
* share with subgroup
* share with specific user

Locations should appear on a map with user markers and names.

Use Google Maps JavaScript API.

---

6. DIRECT CONTACT FEATURE

Users should be able to click on a member profile and directly contact them.

Features:

* view member profile
* see phone number
* initiate phone call

---

7. SMART PROXIMITY ALERTS

The system should detect when two friends are near each other.

Example:
User A location
User B location

If distance between them is less than 200 meters, the system sends a notification:

"Your friend Rahul is nearby (150 meters away)."

Use the Haversine formula to calculate distance between coordinates.

---

8. TRIP TIMELINE / ACTIVITY HISTORY

The application should store location and activity history during the trip.

Example timeline:
10:00 AM – Left hostel
10:30 AM – Arrived at beach
12:00 PM – Lunch at restaurant
2:00 PM – Shopping mall

Users should be able to view the trip timeline and see the sequence of locations visited.
